# Portfolio de projets techniques — Yanis Louaguenouni

Portfolio regroupant une sélection de projets réalisés durant ma Licence Informatique, parcours MIAGE, à l’Université Paris-Saclay.

Licence validée en 2026 et admission en Master MIAGE — Informatique Décisionnelle pour la rentrée 2026. Mes projets se situent à l’intersection du développement logiciel, de l’analyse de données et des systèmes d’information.

## Projets principaux

| Projet | Description | Technologies |

| [Analyse commerciale décisionnelle](https://github.com/ylc26/Projet-SQL-Excel-PowerBI) | Chaîne d’analyse complète : base Oracle, nettoyage, KPI et tableaux de bord | SQL, Oracle, Excel, Power BI |
